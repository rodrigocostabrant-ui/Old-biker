# Old Biker · landing page

Oficina de motos clássicas em BH (Daniel "Tininho" Alcantara). Next.js, estático.

- Rodar: `npm install` (só na primeira vez) e `npm run dev`, abrir http://localhost:3000
- Hero: só o vídeo `public/video/hero.mp4` (8 s, sem som). Ao terminar, aparece o espaço do H1 e da headline (`components/HeroVideo.tsx`, ainda vazio).
- WhatsApp: preencher `WHATSAPP` em `content/site.ts`. Vazio, os botões levam ao Direct do Instagram.
- Desenho original (Claude Design) e brief em `docs/`.
